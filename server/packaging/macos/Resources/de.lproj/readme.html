Nach der Installation

  1. Ersten Administrator anlegen (einmalig), im Terminal:
    sudo -u _david /usr/local/bin/david init
  2. Daemon starten:
    sudo launchctl bootstrap system /Library/LaunchDaemons/com.the-abraham-box.david.plist
    Er startet nach jedem Neustart des Macs von selbst. Fragt macOS, ob david eingehende Netzwerkverbindungen annehmen darf, erlaube es.
  3. Verwaltung öffnen: https://localhost:8484/admin (der Browser warnt vor dem Zertifikat, das David selbst erzeugt: das ist so gewollt; die Apps prüfen seinen Fingerabdruck, den der Kopplungscode mitbringt). Dort die Importordner einstellen und die Apps koppeln (Menü „Koppeln“).

Wo was liegt

  • Programm: /usr/local/bin/david · launchd-Dateien: /Library/LaunchDaemons/com.the-abraham-box.david*.plist
  • Daten (Datenbank, Zertifikat): /Library/Application Support/David (Besitzer _david)
  • Einstellungen der Maschine: /etc/david.toml (eine Aktualisierung behält sie)
  • Protokoll: /var/log/david.log
  • Neustart: sudo launchctl kickstart -k system/com.the-abraham-box.david · Stopp: sudo launchctl bootout system/com.the-abraham-box.david
  • Entfernen: sudo /usr/local/bin/david-uninstall.sh (--purge entfernt auch die Daten)

Musikordner

Der Daemon läuft als _david und muss die Ordner der Bibliothek lesen können (und schreiben, wenn David Tags und Cover ändern oder Uploads annehmen soll). Unter Linux vergibt David diese Rechte selbst mit POSIX-ACLs; auf dem Mac gibst du sie selbst, zum Beispiel für einen Ordner /Users/Shared/Musik: sudo chmod -R +a "_david allow list,search,readattr,readextattr,readsecurity,file_inherit,directory_inherit" /Users/Shared/Musik (Lesen) oder sudo chown -R _david /Users/Shared/Musik (volle Rechte).

Datenschutz (macOS)

Ordner unter Dokumente, Schreibtisch, Downloads, Musik oder auf externen Medien schützt macOS; ein Daemon darf sie nur mit Vollzugriff auf die Festplatte lesen. Lege die Bibliothek entweder in einen gewöhnlichen Ordner wie /Users/Shared/Musik oder gib dem Programm das Recht: Systemeinstellungen → Datenschutz & Sicherheit → Vollständiger Festplattenzugriff → + → Umschalt-Befehl-G, /usr/local/bin eingeben, david wählen, danach den Daemon neu starten.
