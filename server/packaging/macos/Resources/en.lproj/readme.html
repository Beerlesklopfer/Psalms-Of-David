After the installation

  1. Create the first administrator (once), in Terminal:
    sudo -u _david /usr/local/bin/david init
  2. Start the daemon:
    sudo launchctl bootstrap system /Library/LaunchDaemons/com.the-abraham-box.david.plist
    It starts by itself after every restart of the Mac. If macOS asks whether david may accept incoming network connections, allow it.
  3. Open the administration pages: https://localhost:8484/admin (the browser warns about the certificate that David makes itself: that is expected; the apps check its fingerprint, which the pairing code carries). Set the import folders there and pair the apps (menu "Koppeln").

Where things are

  • Program: /usr/local/bin/david · launchd files: /Library/LaunchDaemons/com.the-abraham-box.david*.plist
  • Data (database, certificate): /Library/Application Support/David (owner _david)
  • Settings of the machine: /etc/david.toml (an update keeps it)
  • Log: /var/log/david.log
  • Restart: sudo launchctl kickstart -k system/com.the-abraham-box.david · stop: sudo launchctl bootout system/com.the-abraham-box.david
  • Remove: sudo /usr/local/bin/david-uninstall.sh (--purge removes the data too)

Music folders

The daemon runs as _david and has to read the folders of the library (and write if David should edit tags and covers or take uploads). Linux gives these rights with POSIX ACLs; on the Mac you give them yourself, for example for a folder /Users/Shared/Musik: sudo chmod -R +a "_david allow list,search,readattr,readextattr,readsecurity,file_inherit,directory_inherit" /Users/Shared/Musik (read) or sudo chown -R _david /Users/Shared/Musik (full rights).

Privacy (macOS)

Folders below Documents, Desktop, Downloads, Music or on external disks are protected by macOS; a daemon may only read them with Full Disk Access. Either put the library into a plain folder such as /Users/Shared/Musik, or give the program the right: System Settings → Privacy & Security → Full Disk Access → + → press Shift-Command-G, type /usr/local/bin, choose david, then restart the daemon.
