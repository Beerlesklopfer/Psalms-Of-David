Häufige Fragen

Die App ist leer, was nun?

Psalm braucht einen David-Server. Der Administrator der Familie erzeugt in der Verwaltung unter „Koppeln“ einen Kopplungs-Code. In der App tippst du auf das QR-Symbol (Kamera) oder fügst die Adresse unter dem Code ein und tippst auf „Connect“. Ein Code gilt 15 Minuten und nur einmal.

Ich sehe den Server nicht („The server cannot be reached“)

Prüfe, ob der Server läuft und das Gerät im gleichen Netz ist (oder der Server aus dem Internet erreichbar). Auf dem iPhone muss die Erlaubnis „Lokales Netzwerk“ für Psalm in den Einstellungen eingeschaltet sein.

Ein Titel spielt nicht

Der iPhone-Player kann kein Ogg Vorbis. Ein aktueller David-Server wandelt solche Titel automatisch in MP3 um. Aktualisiere den Server und die App.

Wie lösche ich meine Daten?

Die App speichert nichts außerhalb deines Geräts und deines eigenen Servers. Lösche die App, um ihre Daten vom Gerät zu entfernen. Daten auf dem Server verwaltet der Administrator der Familie.

English

Questions, bugs or wishes about Psalm and David? Write to Joerg@bernau.family or open an issue on GitHub. Psalm needs a David server that your family runs: the administrator makes a pairing code in the administration (page "Pairing"), in the app you scan the QR code with the camera or paste the address, then tap "Connect". A code is valid for 15 minutes and works once. On iPhone, allow "Local Network" for Psalm in the settings. Delete the app to remove its data from the device; data on the server is managed by the administrator of your family.
