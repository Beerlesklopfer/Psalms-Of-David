Häufige Fragen

Die App ist leer, was nun?

Psalms braucht einen David-Server. Der Administrator der Familie erzeugt in der Verwaltung unter „Koppeln“ einen Kopplungs-Code. In der App tippst du auf das QR-Symbol (Kamera) oder fügst die Adresse unter dem Code ein und tippst auf „Connect“. Ein Code gilt 15 Minuten und nur einmal.

Ich sehe den Server nicht („The server cannot be reached“)

Prüfe, ob der Server läuft und das Gerät im gleichen Netz ist (oder der Server aus dem Internet erreichbar). Auf dem iPhone muss die Erlaubnis „Lokales Netzwerk“ für Psalms in den Einstellungen eingeschaltet sein.

Ein Titel spielt nicht

Der iPhone-Player kann kein Ogg Vorbis. Ein aktueller David-Server wandelt solche Titel automatisch in MP3 um. Aktualisiere den Server und die App.

Wie lösche ich meine Daten?

Die App speichert nichts außerhalb deines Geräts und deines eigenen Servers. Lösche die App, um ihre Daten vom Gerät zu entfernen. Daten auf dem Server verwaltet der Administrator der Familie.

Frequently asked questions

The app is empty, what now?

Psalms needs a David server. The administrator of the family makes a pairing code in the administration under "Pairing". In the app, tap the QR symbol (camera) or paste the address under the code, then tap "Connect". A code is valid for 15 minutes and works once.

I cannot see the server ("The server cannot be reached")

Check that the server is running and the device is on the same network (or the server can be reached from the internet). On iPhone, "Local Network" must be allowed for Psalms in the settings.

A title does not play

The iPhone player cannot play Ogg Vorbis. A current David server converts such titles to MP3 automatically. Update the server and the app.

How do I delete my data?

The app stores nothing outside your device and your own server. Delete the app to remove its data from the device. Data on the server is managed by the administrator of your family.
